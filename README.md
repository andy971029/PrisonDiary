# 服刑日誌（網頁版）

楓之谷：經典版的經驗值計算器，整個在瀏覽器裡跑。用瀏覽器的「分享視窗」看遊戲畫面，
讀狀態列的經驗值，算出 EXP/hr 與升級剩餘時間。不用安裝程式，也完全不接觸遊戲程序：
不注入、不讀記憶體、不攔封包，只看分享出來的畫面。

這個 Repo 從 [MapleExpTool](https://github.com/andy971029/MapleExpTool) 拆出來，只留網頁版。
辨識與追蹤邏輯和桌面版是同一套 Python 程式碼，用 [Pyodide](https://pyodide.org/) 在瀏覽器裡執行。

## 使用

直接用 Chrome 或 Edge 開 https://andy971029.github.io/PrisonDiary/ ，什麼都不用裝。
每次 push 到 main，GitHub Actions 會先跑測試，通過才重新打包並發布。

### 在自己電腦跑

需要 Python 3.11 以上（只用來打包與開本機伺服器）和 Chrome 或 Edge。

```powershell
git clone https://github.com/andy971029/PrisonDiary.git
cd PrisonDiary
.\web\serve.cmd
```

1. 用 Chrome 或 Edge 開 http://localhost:8765/ 。
2. 等按鈕從「載入 Python 環境…」變成「分享遊戲視窗」。第一次要下載約 10 MB 的 Pyodide 與 numpy，之後瀏覽器會快取。
3. 按「分享遊戲視窗」，在對話框選「視窗」分頁、挑遊戲視窗。
4. 想邊玩邊看，就按「開啟小浮窗」。

## 功能

- **經驗值與速率：** 用字元模板比對讀經驗值，不用 OCR。實測 OCR 讀數字幾乎全錯。
- **楓幣收益：** 背包視窗開著時讀背包底部的楓幣欄位，算楓幣/hr、最近 10 分鐘與整場的累計。背包可以放在畫面任何位置，程式會自己找（認「楓幣框＋楓葉點數框」上下成對的白框）；拖走或關掉後會重新找。背包關著的時間不計入，短暫被滑鼠擋住則照算。數字用模板比對，沒看過的字形先交給 OCR 讀、讀對了再學起來。
- **角色、職業、等級、地圖：** 用 Tesseract.js 辨識。中文走 `chi_tra`，等級的數字走英文模型。語言檔第一次要下載幾十 MB，之後存在瀏覽器的 IndexedDB。
- **歷史紀錄：** 以「角色 × 地圖」為一段，結算時確認才存進瀏覽器的 localStorage。只存在這個瀏覽器，可以匯出 JSON。
- **經驗加倍試算：** 經驗收益右上角可以選「無加倍」「1.5 倍」「2 倍」（預設無加倍），速率、累計與倒數都照倍數顯示，不影響歷史紀錄。
- **神聖祈禱倒數：** 不用按任何按鈕，分享畫面後就會每格到畫面右上角第一排 buff 裡找神聖祈禱的圖示，視窗模式（buff 在遊戲視窗頂端、不在畫面頂端）找不到時，每 5 秒再到畫面上半部大範圍找一次，找到後就跟著位置走，讀它左下角的剩餘時間。白色數字代表分鐘，顯示「1m+」；剩不到一分鐘會變成黃色的秒數，每讀到一次就校正，兩次截圖之間由網頁自己往下數。圖示快結束時會由下往上變灰，比對時每一列各自正規化，所以灰掉的部分照樣認得出來。寵物重放後自然接到下一輪，不用設定祈禱等級。剩下秒數到「警示倒數」時會用設定好的顏色閃爍與音效提醒；圖示在時間到時消失（寵物沒重放）也會提醒。沒用祈禱時按鈕只顯示「—」。點一下祈禱鈕可以關掉提醒（虛線框、圖示變灰、多一個紅色靜音鈴鐺），倒數照樣顯示，再點一下打開。電腦比較吃力或沒在用祈禱時，可以在「設定」裡關掉「辨識神聖祈禱」，就完全不找圖示，按鈕和其他祈禱設定也會一起藏起來。
- **女神組隊任務小工具：** 主頁有一塊「女神組隊任務」，四關的圖和工具一次排開：休息室（每天要蒐集的唱片，依台北時間標出今天）、封印之室（照著按 NPC 說的 0／1，一步步排出台階人數，最多 5 次）、倉庫（地圖上標好紅獨角獅出現的順序）、中央塔（參考圖），地圖名稱讀到哪一關就把那關框起來。小浮窗角色那一行右邊的「女神」鈕，按下去把經驗、楓幣換成同樣的小工具（用分頁切關卡，進到關卡會自動選好那一關），再按「經驗」換回來；封印之室的進度兩邊共用。
- **功能頁籤：** 頂列左邊標題底下切換「練功助手」（上面這些）與「圖鑑」（怪物、道具、裝備、任務、NPC、地圖）；跟讀畫面有關的東西都在頂列右邊：控制鈕一列、底下是讀到的角色、職業、等級與地圖，在哪一頁都看得到，分享照跑。選了哪頁記在瀏覽器裡，網址加 `#book` 直接開圖鑑。
- **怪物圖鑑：** 從遊戲客戶端的資料檔匯出的快照（`scripts/export_monsterbook.py` 產生 `web/monsterbook.json` 與 `web/mobs/` 的怪物圖，客戶端改版重跑一次；匯出圖要另外 `pip install UnityPy`）。每隻怪的站姿圖（列表是縮圖，展開看大圖，太大的 Boss 縮到 256 像素）、等級、HP、MP、EXP、EXP/HP、物防、魔防、命中、迴避，加上圖鑑卡上列的掉落物與出現地圖（沒有機率，掉落率在伺服器端）。出現地圖不是抄圖鑑卡，是從客戶端的地圖資料（每張地圖的怪物生成清單）算的：客戶端只放已開放區域的地圖，所以沒出現在任何一張地圖的怪就是還沒開放的（武陵、童話王國那些），預設不列，要看打開「含未開放的怪」，展開時會列圖鑑卡上寫的、以後會出現的地方。搜尋同時比對怪物名、型態、掉落物名與地圖名，可以用等級範圍篩、只看「目前地圖的怪」（讀到地圖名稱後才能按），點一列展開圖鑑說明、掉落物與出現地圖；掉落物是帶圖示的小籤，裝備依職業、道具依類別分組，點一個彈出那件東西的小卡（數值、效果、說明、會掉的怪）。預設只列有圖鑑卡的野怪，任務、活動、召喚物要打開「含沒有圖鑑卡的怪」。
- **道具與裝備圖鑑：** 圖鑑分頁裡再分「怪物」「道具」「裝備」。道具與裝備也是客戶端資料的快照（`scripts/export_itembook.py` 產生 `web/itembook.json`，圖示打包成 `web/icons/` 的兩張圖集，要先跑過怪物圖鑑的匯出）。裝備列需求等級、職業、STR／DEX／INT／LUK 需求、攻擊、防禦、其他加成、可升級次數，可以用類別、職業、等級範圍篩；道具列類別、效果（藥水回復量、料理增益與持續時間、卷軸成功率與加成）、等級、商店價。兩邊都有「會掉的怪」：從怪物圖鑑卡反查、只算已開放的怪，展開後是帶怪物縮圖的小籤，點一個彈出那隻怪的小卡（數值、說明），可以只看怪物會掉的；另有「任務獎勵」：接得到的任務會給這個當獎勵的，點一個彈出那個任務的小卡，也可以只看任務給的。商店賣的、NPC 製作的客戶端裡沒有資料（製作配方在伺服器端）。現金裝與現金道具不列。
- **任務、NPC、地圖圖鑑：** 同樣是客戶端資料的快照（`scripts/export_worldbook.py` 一次產生 `web/questbook.json`、`web/npcbook.json`、`web/mapbook.json` 與 `web/npcs/` 的 NPC 站姿圖，要先跑過怪物與道具圖鑑的匯出）。任務列區域、等級、職業、接任務的 NPC、EXP、楓幣、獎勵道具，展開看接／交任務的 NPC、前置與接續任務、要交的道具與要打的怪、獎勵（固定給、擇一、隨機，附職業與性別限制）與接任務前、進行中、完成後的說明；預設只列接得到的（接任務的 NPC 站在已開放的地圖上、活動沒結束）。NPC 列職稱、所在地圖、任務數，展開看對話、所在地圖與接／交的任務；預設只列站在已開放地圖上的。地圖只有客戶端有資料的（已開放區域），列區域、生成的怪與等級範圍、NPC 數、通往幾張圖，展開看怪物（含生成點數）、NPC、相鄰地圖與回程地圖，「目前地圖」一鍵跳到讀到的那張。六個分類互相串：所有小籤（怪物、道具、裝備、任務、NPC、地圖）點了都彈小卡，小卡裡再點就跳到那一列展開。
- **小浮窗：** Chrome / Edge 會開成一直置頂的小視窗，可以疊在遊戲上，經驗與楓幣（楓幣/hr、目前楓幣、總累計）都看得到。它只複製主頁面已經顯示的文字，不另外計算。上方的圖示按鈕可以停止、暫停、重置、縮小或關閉。縮小後只留狀態燈、經驗速率、升級倒數與楓幣速率。其他瀏覽器會退回一般彈出視窗，不會置頂。

讀不到數字時，展開頁面最下方的「診斷」，會放大顯示程式實際看到的像素。

## 結構

```
web/
├── index.html        介面、歷史紀錄、小浮窗（JS）
├── bridge.py         在 Pyodide 裡跑的膠水層：canvas 畫面 → 辨識 → 追蹤 → JSON
├── mapvocab.json     地圖名稱清單快照，用來校正 OCR 讀到的地圖名
├── monsterbook.json  怪物圖鑑快照：數值、掉落物、出現地圖與名稱表
├── itembook.json     道具與裝備圖鑑快照：數值、效果、說明與掉落來源
├── questbook.json    任務圖鑑快照：條件、需求、獎勵、說明
├── npcbook.json      NPC 圖鑑快照：職稱、對話、所在地圖
├── mapbook.json      地圖圖鑑快照：生成的怪、NPC、傳送點通往的地圖
├── icons/            道具與裝備的圖示圖集（equips.png、items.png），JSON 記格子序號
├── mobs/             怪物站姿圖，一隻一張 PNG，檔名是怪物 ID
├── npcs/             NPC 站姿圖，一個一張 PNG，檔名是 NPC ID
└── serve.cmd         打包 + 開本機伺服器
src/mapleexp/
├── vision/           二值化、切割、模板比對、定位、面板與身分辨識
├── core/             讀值解析、追蹤狀態機、統計、經驗表反推
├── gamedata.py       解客戶端的 UnityFS bundle，撈 JSON 字串表（地圖、怪物、物品名稱）
├── wzjs.py           解客戶端的 WZJS 二進位節點樹（舊版 .wz 搬過來的怪物數值、圖鑑）
├── spritesheet.py    解客戶端的圖集（哪一格圖在貼圖的哪裡），匯出怪物圖與道具圖示用
├── itembook.py       把裝備數值、道具效果、名稱表、掉落來源合成 web/itembook.json
├── monsterbook.py    把數值、圖鑑、名稱表合成 web/monsterbook.json
├── worldbook.py      把任務、NPC、地圖的資料與名稱表合成 web/questbook.json、npcbook.json、mapbook.json
├── win32/capture.py  只有型別的替身；真正的擷取由瀏覽器的 getDisplayMedia 做
└── builtin_templates.json   內建字元模板
scripts/
├── build_web.py      把 src/mapleexp 打包成 web/mapleexp.zip
├── export_mapvocab.py     從本機客戶端匯出 web/mapvocab.json
├── export_monsterbook.py  從本機客戶端匯出 web/monsterbook.json（要裝 lz4）
├── export_itembook.py     從本機客戶端匯出 web/itembook.json 與圖示圖集
├── export_worldbook.py    從本機客戶端匯出任務、NPC、地圖圖鑑與 NPC 圖
└── serve_web.py      送 no-store 的靜態伺服器，改了檔案重新整理就生效
```

## 測試

測試都不需要遊戲或瀏覽器：視覺管線用 `src/mapleexp/testfont.py` 的點陣字型合成畫面，
`tests/test_web_bridge.py` 在一般 CPython 下直接匯入 `bridge.py` 驗證。

```powershell
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python -m unittest discover -s tests -t tests
```

`tests/` 不是套件，`tests/helpers.py` 負責把 `src` 放進 `sys.path`。
